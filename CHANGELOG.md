# Changelog

## 1.1.0 — 2026-11-16

Baseline del alcance probado, no promoción global de capacidades runtime.

### Incluido
- Ciclo DISCOVER → DEFINE → PLAN → EXECUTE → VERIFY → DELIVER y cuatro roles con responsabilidad de integración única.
- Selección DIRECT / CONTEXTUAL / EXPLORATORY; tres skills propias y piloto interview-me adoptado sin modificar upstream.
- Política de continuidad, contrato JSON por trabajo, plantilla y validador local con 18 pruebas unitarias.
- Documentación portable, bootstrap manual del índice privado y exclusiones de proyectos, sesiones y dependencias.
- Licencia MIT para el material propio; licencia y copyright upstream de interview-me conservados por separado.

### Límites conservados
- Evidencia histórica favorable de un ciclo conversacional real hasta PLAN en el mismo contexto, con STOP sin herramientas y persistencia posterior autorizada; no demuestra recuperación entre sesiones primarias.
- interview-me y routing mantienen ramas/cobertura pendientes; T2 cross-session permanece UNKNOWN.
- No motor de workflows ni enforcement nuevo de autorizaciones; no adaptador ejecutable para Claude Code.
- La fecha y esta entrada describen el contenido de la versión; no acreditan por sí solas su publicación remota ni un historial de versiones anterior. La distribución se verifica mediante el tag correspondiente.
