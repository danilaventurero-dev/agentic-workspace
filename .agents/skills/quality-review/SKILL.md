# Quality Review

1. Identificar criterios de aceptación del brief.
2. Revisar adecuación, exactitud, coherencia, límites y completitud.
3. Para cada criterio asignar PASS, FAIL o UNKNOWN con evidencia.
4. Priorizar hallazgos por impacto y proponer corrección.
5. Indicar expresamente verificaciones no ejecutadas.
