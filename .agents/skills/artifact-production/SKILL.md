# Artifact Production

1. Identificar audiencia, formato objetivo, alcance y criterios.
2. Elegir el formato de salida más apropiado, sin asumir que siempre es código.
3. Dividir en unidades que puedan revisarse; cuidar coherencia de versiones.
4. Documentar decisiones relevantes y supuestos.
5. Preparar artefactos para revisión y comprobar formato y completitud.
